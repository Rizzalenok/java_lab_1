### Алгоритм решения

## Задача 5
### Текст задачи
Тройной максимум.

Необходимо реализовать метод таким образом, чтобы он возвращал
максимальное из трех полученных методом чисел. Подсказка: идеальное
решение включает всего две инструкции if и не содержит вложенных if.
### Алгоритм решения
Принимет числа x, y, z инициализирует переменную maxNum, присвоив ей значение числа х, выполняет проверку if maxNum < y,
если истинно присваивает переменной maxNum значение у, выполняет вторую проверку if maxNum < z, если истинно присваивает
переменной maxNum значение z и в конце возвращает значение переменной maxNum
